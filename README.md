# Последний километр

Браузерная 3D-игра о выживании после зомби-апокалипсиса. Пройди 500 км на Porsche, помоги Ане и собаке Рэю, найди припасы и доберись до последнего эвакуационного рейса из аэропорта Северный.

## Управление

WASD — ехать или идти, Shift — нитро / бег, F — выйти / защита, E — сесть / взаимодействовать, пробел — ручной тормоз / прыжок. Мышь — обзор, 1 / 2 / 3 — камеры, M — карта, J — дневник, Q — еда, R — сон. L (Д на русской раскладке) — фонарик пешком / фары в машине.

## Публикация

Готовый сайт находится в `site/`. В настройках репозитория **Settings → Pages → Source** выбери **GitHub Actions**. Workflow `.github/workflows/pages.yml` проверяет файлы и публикует сайт после отправки в `main`.

Для обновления из свежей автономной версии игры:

```sh
node tools/package-static.mjs /path/to/offline/index.html
node tools/validate.mjs
```

Первый запуск загружает модели и звуки. Игра использует WebGL; для управления нужны клавиатура и мышь.

Сведения об авторах моделей и звуков находятся в [CREDITS](site/CREDITS.txt). Разрешения на сторонние материалы описаны отдельно; единой лицензии на все ресурсы не назначено.

## Слабые ПК

После этого обновления включается облегчённый LOW. В меню «Изображение» оставьте LOW и адаптивное разрешение. Оптимизированы память, трава, дальние объекты, облака и число отдельных частей машины при отрисовке. Сюжет и сохранения совместимы с прежней версией.
